Trust, without stars

What is built

Discovery

Browse, typo-tolerant search, filters, saved sellers, Featured Hustle rotation, low-data mode.

Enquiries and messaging

One conversation per buyer, seller and listing. Realtime, optimistic send with retry, private photos, rate limits.

Seller tools

Listings, onboarding wizard, enquiry dashboard, quick replies, buyer-confirmed completion.

Safety by design

Row Level Security on every table, no contact details in page HTML, WhatsApp handoff logged, mentors cannot read messages.

Try it yourself

  1. Clone the repo, add your Supabase keys to .env.local, run npm run build && npm start.
  2. Open two phones (or two browsers). Sign in with the demo buyer on one and Thandi's Kitchen on the other.
  3. Enquire, reply, complete and confirm. The full script is in the README.
